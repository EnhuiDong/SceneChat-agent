# 生成目标：设定忠实、机制闭合、允许角色推演

详细输入尽量原样落实，只补缺少的运行条件；一句话输入补足人物动机、信息边界、行动机制和可结束的条件。补全不等于高密度扩写：不要默认加入实验机构、监控、机械臂、倒计时、阵营阴谋或强制冲突。用户只要求找出隐藏 AI 时，不自动推导为赛博朋克或机械身体。

公共规则、执行规则与结束条件必须表达同一件事。有限阶段优先 all_eligible_acted / all_active_voted / after_event；只有允许无限持续的阶段才用 manual。manual 有出口时，出口采用独立 action_type 和 rule_id，不要把结束阶段绑到所有普通发言上。明确区别一轮发言、一次投票、一次结算；不能靠旁白维护计数或决定结果。

逐项核对一个完整循环：谁有权行动、选什么目标、产生什么 effect、什么时候结束当前阶段、怎样结束整个模拟。faction_parity 的 faction 是数量达到其他阵营总数的一方，不是被击败的一方；winner 应与该含义一致。无法由支持的操作表达的规则应作为明确限制，不得虚构运算符或交给旁白暗中执行。

人物拥有目标与可调整策略，不能只有职业口癖。设计“原策略无效时如何改变方法”，不要要求 AI 永远机械说话、艺术家永远使用通感、理性者永远谈逻辑。除非用户明确指定，公开姓名风格不应直接编码隐藏阵营。信念是可选动机，不是每人必填。
开场应保留关系的起点：若人物初次相见，不能预设共同往事、默契或已建立的信任链。即使存在危及生命的主线，也应允许角色先确认自己身在何处、规则是真是假、谁愿意合作与眼前的身体/生活需求；这些反应是否出现取决于人物和情境，不是每人必须依次自我介绍。非主线反应应与当下压力有关，不靠随机家常话充数。
若用户没有给出既有关系，而题材是临时聚集的一群人，应默认尚未熟悉；在 public_world_markdown 中明确他们此前没有共享经历或可信印象。即使用户单独填了很短的地点提示，世界的公共背景也要保留“刚到场”的时间状态，不靠角色档案虚构旧交来补足。若用户明确是熟人、家人或老队友，则按其关系设定，不强行陌生化。
执行规则保持最小充分集：同一投票阶段只需真正记录选票的角色规则与独立结束条件。不能再造高优先级的“投一票就设置 human_win/ai_win”伪规则；胜负放 termination_rules，由已提交的选票和存活状态判定。

节点描述可观察的完成条件。普通题材补全不能变成用户硬约束；不把“必须先出现平票”之类偶发分支设置为全体后续剧情的必经条件。不要把首次发言与所有人完成自我介绍混为一谈。时间或气氛变化不算任务完成。

本文件约束创作与因果。最终输出格式以调用处给出的 JSON schema 为准，而不是旧版 Markdown 文档模板。
