# 同场景策略评测

结构合法、流程未报错和故事结束，不能替代对白质量。策略变更应先比较实际文本，再决定是否进入默认推演路径。

## 控制输入，而不是比较不同故事

同一组保留完全相同的世界、人物、可见知识、历史、初始运行状态、模型和公开配置。修改生成立场时，不同时补写人物经历、删除性格、缩短历史或给某一组额外秘密。后续分支允许因实际选择而不同，但应保留每次真实请求与输出。

`scenechat.strategy_review.strategy_prompt` 是可选实验变换，不接管默认演员路径：

| 策略 | 修改内容 |
| --- | --- |
| `production` | 原始演员提示，原样返回 |
| `identity` | 从本人位置回应，去掉本节点的推进机会 |
| `director` | 从外部编写此人言行，去掉本节点的推进机会 |
| `identity_bias` | 本人位置回应，保留本节点已触发的推进机会 |
| `director_bias` | 外部编写言行，保留本节点已触发的推进机会 |

实验导演与演员使用相同的有限所知。它不是全知导演 agent，不接收幕后真相、其他人物私密档案或未来情节。变换保留原始参考资料、执行协议和通用对白合同；这是立场提示的对照，不是对完整多 agent 架构的验证。

推进机会仍由原有代码判断，不凭测试策略制造事故、强制人物改变主意或绕过权限。未触发机会时，有/无机会的两个版本可能完全相同：相同请求可复用一次输出，并注明不是两个独立样本；不能据此评价推进因子的收益。

推荐先用固定节点的一次回应筛选，再从相同起点继续数轮。即时生成案例应只生成一次世界和人物，再供所有策略共用；另外保留未参与调优的题材与模型作复核。历史重放构建的受控起点必须注明，不将其称为原运行的精确检查点。

## 给人看的报告

私有评测驱动器可将结果整理成数组，交给离线工具：

```bash
python -m scenechat.strategy_review private-results.json --output data/evaluations/strategy-review.md
```

此命令不调用模型。每行至少提供 `case`、`model`、`variant`、`scenario_hash`、`initial_state_hash`、`reference_hash`、`protocol_hash`；`trial` 默认 1。摘要须从实际输入计算，不由模型猜测。`events` 中的 `speaker`、`speech`、`action` 是实际留存原文，不能使用润色后的台词；可附 `tokens`、`status`、`context` 和运行 `summary`。

工具按场景、模型和样本检查输入摘要是否一致、策略是否重复，确定性打乱展示顺序，先展示匿名原文，末尾给出策略答案。它只校验提供的摘要，不证明摘要来源真实；调用方仍须保存完整原始输入以便审计。报告不展示 `private_reason`、原始 JSON 或私人记忆；读者可见旁白须明确标注，不能当作人物知道的事。

报告和输入可能包含私人剧情或秘密，应存放在忽略目录，不提交公共仓库。不要把 API Key、服务地址、环境变量或数据库作为评测元数据。

## 评价口径

先判断是否守住设定、信息边界与因果权限，再评价以下内容，并引用具体事件或句子：

- 活人感：话是否真在对眼前的人说，还是解释场景、分析角色、汇报任务。
- 人物差异：在意什么、如何对待别人、选择付出什么，而不只是换口癖。
- 实质承接：别人刚回答、拒绝或让步，是否改变了下一次回应。
- 场景发展：信息、选择、关系、行动或代价是否真实变化，而非同义改写或反复准备。
- 整段阅读体验：是否有重复、无意义细节、强行转折与靠捏造往事得到的“感人”。

自然沉默、分歧、暂未行动不自动扣分。台词长、粗口多、情绪强、结束快也不自动加分。未知调用用量不算零；兜底、重试和错误单列，不作为人物真实态度。观察窗口结束时，没有实际观察到结局就不评价完整收尾。

分别写出“这组中相对更好”和“是否达到绝对质量要求”。少量单次采样只用于筛选方向，不支持总体胜率或跨模型普遍优势。人的判断与模型评审都可能有偏差；应保留原文、展示顺序、评价依据与未覆盖的边界供复核。

重复应按功能而非词频评价：呼应、反讽、强调、试探或同一句话意义的改变，可以比不重复更有分量；换词重索保证、反复准备和工序拆分不能仅凭词面差异得分。细节看它是否显出情感、矛盾、关键事实或代价，不按描写数量加分。

比较完整模型输入时，同时记录旁白模式、补写权限、检索范围、调用路径与输出预算。只换了同一人物立场的实验，不能与同时换了历史窗口、知识检索或旁白策略的实验混称单因素对照。包含新编过去的好段落须标出，不以感染力抵消设定错误；当前愿望与明确的未来想象则不要求预先写在档案里。
